# Research PDF Manager

**Official releases and updates for Research PDF Manager**

Research PDF Manager is a Windows desktop application designed to help researchers organize, review, merge, sort, and manage research PDF files in one place.

## Current version

**v1.2.9**

## Main features

- Organize research PDFs by year.
- Merge selected files, a full year, or the entire library.
- Detect duplicate files and review them before removal.
- Preview PDFs inside the application.
- Search and manage research metadata.
- Favorites and thesis-related article marking.
- Arabic and English interface.
- Local-first research library: research files remain on the user's computer.
- License, update, and notification checks use the internet only when needed.

## العربية

**Research PDF Manager** هو برنامج مكتبي لنظام Windows مخصص لتنظيم وإدارة ملفات الأبحاث بصيغة PDF.

يوفر البرنامج تنظيم الملفات حسب السنة، الدمج، كشف الملفات المكررة، المعاينة داخل البرنامج، إدارة بيانات المقالات، والمفضلة، مع دعم الواجهتين العربية والإنجليزية.

ملفات الأبحاث تبقى محليًا على جهاز المستخدم ولا يتم رفع محتواها إلى خوادم البرنامج.
