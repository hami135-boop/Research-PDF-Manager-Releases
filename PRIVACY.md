# Privacy — Research PDF Manager

Research PDF Manager is designed as a local-first desktop application.

## Research files

The application does **not** upload research PDF files, PDF contents, filenames, or the user's research library to the licensing/update service.

PDF processing and library management are performed locally on the user's computer.

## Internet use

Internet access is limited to application services such as:

- License activation and license status checks.
- Update availability checks.
- Application notifications.

The application does not require a permanent internet connection for normal local PDF management.

## Data used for licensing

When the user performs licensing-related actions, the application may send limited technical information required to identify the licensed installation, such as the application device identifier and application version.

No research PDF content is included in these requests.

## Releases

Users should download installers only from the official Releases section of this repository.
